📌 Как пользоваться VPN (прочитайте)

Если включили VPN и пропал интернет — **выключите VPN в клиенте**. Kill switch / TUN при мёртвом туннеле режет весь трафик. Не ждите.

В боте два ключа. Не один «на все сети»:

🏠 **Дом** — домашний Wi‑Fi, офис. Сначала этот.
📱 **Мобильный** — только сотовая сеть / если дом не коннектится.

⚠️ Трафик: мобильный ключ идёт через платный CDN. На Wi‑Fi (дом, офис, кафе) включайте **🏠 дом**, не держите 📱 сутками. YouTube/загрузки на мобильном ключе тоже жрёт общий бюджет. Если клиент умеет «только для сотовой / правила по сети» — так и настройте; иначе просто переключайте профиль.

Продление подписки: если ключи уже импортированы — после оплаты они снова работают, профиль в приложении менять не нужно. «Подключиться» — чтобы получить ключи в первый раз или если админ просил переимпортировать после смены сервера.

Почему два ключа: у Ростелекома, Билайна, МТС, Tele2 списки разные. У кого-то жив дом и мёртв мобильный, у кого-то наоборот.

Клиенты
• Android — v2rayNG (APK из бота)
• iPhone — INCY (российский App Store)
• Windows / Mac — Happ
• Hiddify можно **только** для ключа «Дом». Мобильный CDN в Hiddify не работает.

Как подключить: бот → Подключиться → скопировать ключ → импорт из буфера → Connect.

Ключ персональный. В группу vless:// не кидать.

Взнос 100 ₽ / мес (Stars или СБП), чтобы сервер жил.

Если не встаёт — напишите: оператор, дом или мобильный интернет, клиент, скрин ошибки.
