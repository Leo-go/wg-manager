📌 Как пользоваться VPN (прочитайте)

Сейчас пользуйтесь ключом 🏠 **Дом**. Мобильный (CDN) на части сетей временно чиним — его не мучайте и в группу не пишите «CDN не работает», это известно.

Если включили VPN и пропал интернет — **выключите VPN в клиенте**. Kill switch / TUN при мёртвом туннеле режет весь трафик. Не ждите.

Как получить ключ
1. Бот → **Подключиться**
2. Копируете ключ **🏠 ДОМ** (не мобильный)
3. В клиенте: импорт из буфера → Connect

Ключ персональный. В группу vless:// не кидать.

Клиенты для домашнего ключа
• Android — v2rayNG (APK из бота)
• iPhone — INCY (российский App Store)
• Windows / Mac — Happ (удобнее, чем v2rayN)
• Hiddify — только для ключа «Дом»

Дом — домашний Wi‑Fi и офис. На части мобильного интернета этот ключ тоже живой; если нет — напишите (оператор + клиент), не перебирайте мобильный ключ пока.

Взнос 100 ₽ / мес (Stars или СБП), чтобы сервер жил.
